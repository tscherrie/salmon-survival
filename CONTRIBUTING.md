# Contributing

Thanks for wanting to help!

- **Feedback and bugs:** open an [issue](https://github.com/tscherrie/salmon-survival/issues). A screenshot, your browser and what you were doing help a lot. The version is on the start card.
- **Ideas:** new fish, plants, places, events, translations — open an issue first so we can talk it through.
- **Pull requests:** welcome. Keep the style of the code (plain ES modules, no build step, comments that say what a thing is and why). Try your change in the browser (see "Run it yourself" in the README), ideally at a few places along the river and in more than one stage of life, and keep an eye on the frame rate.
- **Translations:** the game is written in German; `src/i18n-en.js` maps the German to English, `src/i18n-zh.js` the English to Chinese. A new language is a new table keyed the same way, plus its name in `LANGS` in `src/i18n.js`.

This repository is published from a larger development tree, so merged changes may come back in a slightly different shape.
