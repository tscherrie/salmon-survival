Data practices — development draft

AI Director Studio stores owner-scoped projects, documents, version history, asset metadata, approvals and job receipts in the Site's database. Uploaded media and generated exports are stored in its object storage. The server uses the Site-provided user ID to authorize project access. It does not collect your model provider API keys or read the host's entire conversation history or memory.

The selected project and selection references can be supplied to the native host as context. Media generation and transcription use the separately connected fal plugin and that service's account and terms. Studio records receipts supplied by the host; it does not retrieve fal account tokens.

Browser rendering uses your device and may require memory proportional to source media. Device preferences may be stored locally. Project records persist until an authorized deletion; deployment updates preserve them. There is no public retention promise or service guarantee in this development build.

Before public release the publisher must confirm the controller/contact, retention and deletion support, legal basis, regional scope and final policy. This draft is not an approved public privacy policy.
