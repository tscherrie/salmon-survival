The Worker returned HTML successfully, but the host rejected it before UI initialization or JavaScript execution. The sanitized observation is `evidence/native-host-resource-failure.json`. The server advertised MCP 2026-07-28 without implementing its [mandatory cacheable-result fields](https://github.com/modelcontextprotocol/modelcontextprotocol/blob/main/schema/2026-07-28/schema.json). Discovery, tool/resource lists and resource reads now use immediately stale, authorization-private cache hints. The editor resource URI derives from the HTML SHA-256, following OpenAI's [resource cache-key contract](https://developers.openai.com/plugins/build/chatgpt-ui). The old URI remains readable for existing conversations. The app declares inline/fullscreen capabilities during initialization, and a delayed fullscreen request cannot block project loading.

The original MCP resource depended on private HTTP JavaScript/CSS/font downloads. Anonymous private Site requests return 401, and native MCP OAuth does not automatically authenticate iframe HTTP requests. The build now emits self-contained native editor and media-sandbox HTML with embedded modules, styles, fonts and images. `resources/read` delivers the complete editor. Runtime compiler/codec files travel in bounded authenticated `director_ui_request` ranges, with path checks and integrity validation. The generated sandbox receives only static runtime bytes through its controlled MessagePort, never an owner credential or a general authenticated API capability.

An opaque native frame cannot use the same module Blob Worker path as the standalone editor. The native codec adapter uses a classic Blob Worker with the pinned classic FFmpeg core. Authored TSX executes through a sandbox-only inline script loader without `new Function`. An explicit media-sandbox role, activated only in the child entrypoint, prevents the outer opaque authenticated editor from being mistaken for that child. Visual generated code and website processing must use the child; opaque origin alone is insufficient.
