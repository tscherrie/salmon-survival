## Background-media lifecycle regression

The intermediate ENOTEMPTY failure was traced to the unchanged baseline backend starting an untracked thumbnail→peaks→proxy chain, then closing its store while writes continued. Production now tracks each complete chain and drains it on close before updating recents/closing the store. A deterministic held-peaks regression verifies close remains pending until proxy completion; the original recent-project test also passes.
