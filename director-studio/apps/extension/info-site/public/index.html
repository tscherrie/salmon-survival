AI Director Studio

Plan, edit and export video, audio, presentations, graphics and websites with your selected ChatGPT Work or Codex model.

AI Director Studio keeps the project brief, source material, document versions, checkpoints and processing receipts together in an interactive editor. It is an independent project operated by Jeremias Grenzebach.

Work with your own material

Import your files, arrange video or audio on a timeline, edit slides or a canvas, and preview authored websites in an isolated frame. Inspect earlier versions and restore them while keeping history. Selected clips, assets, markers and elements can provide project references for your next chat turn when the host supports it; a copyable context is available as a fallback.

Exports are stored in the project and offered for download. Supported formats include video MP4/MOV, audio WAV/MP3/M4A/FLAC, slides PDF/PPTX/PNG, graphics PNG/JPEG/PDF/SVG and website ZIP. Browser capabilities, source formats, fonts and available resources affect individual operations. Browser processing needs an open editor. A queued job is not a completed export.

Free editor, separately paid generation

Director Studio is free and does not accept payments. Your ChatGPT or Codex plan and limits apply separately. New AI media generation and transcription use the separately installed official Fal plugin and your connected Fal account. Obtain a current quote and approve a paid request before submission. Director does not require its own model-provider API key.

Application-authored source is available under the repository's MIT license. Dependencies, codecs and fonts retain their own licenses and notices. See the source repository and dependency license inventory.

Access and current scope

Availability is selected for all countries offered by OpenAI. The working preview is currently restricted to authorized accounts; a public directory listing has not yet been published. Open the editor if your connected account has access.

Native file-library import or delivery depends on capabilities exposed by the host. A download does not by itself establish a Library save. Direct native opening of .dstudio files is not implemented. Host plans, browser resources and network availability can limit operations.
